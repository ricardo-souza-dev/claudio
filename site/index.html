O que você precisa saber antes de deixar um agente entrar no seu projeto.

Como o aplicativo é atualizado?+

O app instalado consulta novas versões no GitHub. Você escolhe baixar e depois reiniciar para instalar. A instalação é bloqueada enquanto um agente estiver trabalhando. Conversas e configurações ficam fora da pasta do programa; recomendamos manter cópias de segurança antes de atualizar uma versão de testes.

Meus dados ficam só no computador?+

Conversas e configurações são guardadas localmente. Ao conversar, o histórico e os dados necessários são enviados ao provedor que você escolher. Ferramentas MCP também podem se conectar a serviços externos. Chaves salvas são criptografadas pelo sistema operacional.

O agente pode executar qualquer comando?+

Por padrão, alterações e comandos pedem sua aprovação. Não há sandbox: um comando aprovado roda com as suas permissões. Use Git, revise o que vai executar e faça backups. Ainda não existe um botão para desfazer todas as alterações do agente.

O que ainda está em desenvolvimento?+

O Claudio está em testes. Conversas longas ainda não têm compactação, comandos não exibem saída ao vivo e a validação com APIs reais ainda é limitada. Consulte o README para o estado atual antes de usar em trabalho importante.

O Claudio é da Anthropic?+

Não. É um projeto independente, sem vínculo com a Anthropic ou com os outros fornecedores conectados.
